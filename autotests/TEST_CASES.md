# Тест-кейсы

Один набор сценариев реализован на нескольких языках. Номер кейса (TC-API-xx, UI-xx) одинаковый
во всех реализациях — по нему удобно сверять отчёты и заводить кейсы в Allure TestOps.

## API

| ID | Сценарий | Ожидаемый результат |
|----|----------|---------------------|
| TC-API-01 | `GET /api/health` | 200, `{"status":"ok"}` |
| TC-API-02 | `GET /api/config` | 4 сектора A–D по 60 гвоздей, пресеты 30–70 см, скорость 2,0 с / шаг 0,1 / 0,5…10 с, запас 15 %, линии 1000…5000 |
| TC-API-03 | `POST /api/projects` с JPEG, 50 см | 201; id из 12 hex; число линий = `best_lines` из TC-API-26 (максимум сходства с фото); шаг 1; скорость 2,0; sequence из 5001 гвоздя, первый — A1 (0); катушки хватает на длину с запасом |
| TC-API-04 | Загрузка PNG с прозрачностью без названия, 70 см | Название = имя файла без расширения; число линий = максимум сходства для 70 см |
| TC-API-05 | Пустой файл / не картинка / диаметр 19,9 / 150,1 / «abc» | 400 / 400 / 422 / 422 / 422 |
| TC-API-06 | `POST` без файла | 422 |
| TC-API-07 | `GET /api/projects` | Проект в списке, без поля `sequence` |
| TC-API-08 | `GET` несуществующего / кривого id | 404 |
| TC-API-09 | `PATCH current_step=137` | Шаг сохраняется и читается обратно |
| TC-API-10 | `PATCH speed_sec` 2,1 / 1,9 / 2,04999 / 0,5 / 10 | Сохраняется с точностью 0,1 с |
| TC-API-11 | `PATCH` скорость 0,4 и 10,1; шаг 0 и > линий; линии 999 и 5001; диаметр 10; пустое имя; лишнее поле | 422 |
| TC-API-12 | Линий 2000, шаг 1900, потом линий 1500 | Шаг подтягивается до 1500 |
| TC-API-13 | `PATCH diameter_cm=100` | Последовательность не меняется, длина лески ×2 |
| TC-API-14 | `GET /steps` | Шаг 1 начинается с A1; конец шага = начало следующего; расход лески растёт; последняя страница обрезана по числу линий |
| TC-API-15 | `GET preview.png`, `source.png` | 200, PNG; size=50 → 422 |
| TC-API-16 | `GET instructions.pdf` при 1000 линиях | `application/pdf`, attachment c UTF-8 именем, 7 страниц (обложка + схема + 5 страниц шагов) |
| TC-API-17 | `DELETE` | 204, затем `GET` → 404, повторный `DELETE` → 404 |
| TC-API-18 | `GET /api/geometry` для 30 / 50 / 70 см | Шаг по дуге 3,93 / 6,54 / 9,16 мм; ориентир 1200 / 2000 / 2800 линий (40 на 1 см; для нового портрета используется рекомендация по сходству) |
| TC-API-19 | `POST /api/images` с фото человека | 201; размер, найденное лицо, готовый кадр `face_prep` с `face_focus=true`; `original.jpg` отдаётся |
| TC-API-20 | `GET /api/images/{id}/prepared.png` с яркостью и зумом | 400×400; ярче и иначе скадрировано, чем без параметров; zoom 5 → 422 |
| TC-API-21 | `POST /api/projects/from-image` с кадром и контрастом | 201; `prep` сохранён; схема отличается от портрета без правок; неверные параметры → 422, чужой id → 404 |
| TC-API-22 | «Выделить лицо» | с лицом — 201 и `face_focus=true`; на фото без лица — 422 с понятным текстом |
| TC-API-23 | `PUT /api/projects/{id}/photo` | схема пересчитана, прогресс сброшен на шаг 1; zoom 9 → 422 |
| TC-API-25 | `GET /` на бэкенде | 307 на приложение http://localhost:3000; `/favicon.ico` → 204 |
| TC-API-24 | Удаление фона: `POST /api/images/{id}/mask` → опрос `GET …/mask` → `GET …/mask.png` | POST отвечает сразу (202), даже если модель грузится; статус доходит до `ready`; маска: человек белый, фон чёрный; до готовности `mask.png` → 409; ошибка модели видна в статусе; без rembg — 503 с подсказкой; `/api/config` не импортирует rembg |
| TC-API-26 | `GET /api/projects/{id}/similarity` (+ `?diameter_cm=30/100`) | Кривая сходства (детали + тон) 1000…5000 линий с шагом 100; `best_lines`/`best_score` — её максимум, `best_score` > 0,2; на 30 см максимум не позже, чем на 50, на 100 см — не раньше; диаметр 10 → 422; чужой id → 404 |
| TC-API-27 | `POST /api/images/{id}/auto-tone` | 200; яркость и контраст в допустимых пределах; сходство после ≥ до; перебрано 6 вариантов; диаметр 5 → 422; чужой id → 404 |
| TC-API-28 | Кисть: `PUT /api/images/{id}/mask.png`, `DELETE /api/images/{id}/mask/edits` | Пустое тело / не PNG → 400; PNG другого размера и RGBA приводится к размеру фото; `edited=true`; стёртая область на подготовленном кадре белая; сброс возвращает автоматическую маску; маски старой версии пересчитываются; чужой id → 404 |
| TC-API-29 | Десктопная версия: бэкенд раздаёт `frontend/out` (`STRINGART_STATIC_DIR`) | `/` → index.html, `/project` → project.html, `/_next/static/*` с долгим кэшем, неизвестная страница → 404.html, выход за папку (`../`) → 404, `/api/*` работает как обычно; без переменной `/` → 307 на :3000 |
| TC-API-30 | `POST /api/projects/{id}/activity`, `PATCH own_spool_m` | Время и шаги складываются по дням; итог и список дней в ответе и в проекте; дата не ГГГГ-ММ-ДД, >600 с, отрицательные шаги, лишнее поле → 422; `own_spool_m` сохраняется, `null` сбрасывает, <10 → 422; `/api/config` отдаёт версию программы |
| TC-API-31 | `GET /api/projects/{id}/template.pdf`, `GET /api/template.pdf?diameter_cm=…&paper=A4\|A3` | PDF; инструкция + листы A4 в натуральную величину; все 240 подписей A1…D60 на листах; 50 см — 6 листов A4; бумага A5 → 422; диаметр 10 → 422; чужой id → 404 |

## UI (Playwright)

| ID | Сценарий |
|----|----------|
| UI-01 | Выбор не-картинки показывает ошибку, кнопка «Сделать портрет» неактивна |
| UI-02 | Загрузка фото, название, 70 см → студия: линий столько, сколько рекомендует кривая сходства, шаг гвоздей 9,16 мм, катушка, превью и график сходства нарисованы |
| UI-03 | Ползунок и свой диаметр меняют расчёт мгновенно и сохраняются после перезагрузки |
| UI-04 | Кнопка «Скачать инструкцию PDF» отдаёт настоящий PDF |
| UI-05 | Удаление портрета с подтверждением возвращает на главную |
| UI-06 | Несуществующий проект и адрес без id — понятное сообщение |
| UI-07 | Автоперелистывание с 2,0 с, кнопки ±0,1 с, шаг и скорость переживают перезагрузку, текущий шаг совпадает с API |
| UI-08 | Режим «Голос» произносит гвоздь по-русски («Цэ 37») |
| UI-09 | Прогресс плетения виден в карточке и на кнопке «Продолжить с шага N» |
| UI-10 | Редактор: «Выделить лицо» ставит кадр на лицо, яркость и сдвиг мышью сохраняются в проекте |
| UI-11 | Редактор: «Убрать фон» (пропускается, если на сервере нет rembg) |
| UI-12 | Правка фото готового портрета: предупреждение о сбросе прогресса, пересчёт, прогресс с шага 1 |
| UI-13 | При 1000 линиях видна кнопка «Поставить N» — ставит рекомендацию по сходству и сохраняет её |
| UI-14 | «Автонастройка» в редакторе: выделяет лицо, подбирает яркость/контраст, показывает рост сходства |
| UI-15 | Файл с компьютера на сцене: плейлист, играет на «Старт», встаёт на «Пауза»; ссылка YouTube сохраняется после перезагрузки |
| UI-16 | Переключатель тёмной/светлой темы, выбор переживает перезагрузку |
| UI-17 | Кисть: «Стереть» двумя мазками, «Отменить» второй, правка маски сохраняется (`edited=true`) и портрет считается с ней |
| UI-18 | Старые адреса `/projects/<id>` и `/projects/<id>/weave` перекидывают на `/project?id=…` |
| UI-19 | Ноутбук 1366×768 и телефон: с фильмом на сцене видео, шаг «откуда → куда», кнопка «Старт» (и схема на ноутбуке) видны без прокрутки; «Кино» — на весь экран с шагом поверх, кнопки шагов работают, выход |
| UI-20 | Графа «Музыка»: код Яндекс Музыки → плеер с названием плейлиста; код VK Видео («Экспортировать») → видео на сцене; музыка не пропадает, обе графы помнятся после перезагрузки |

| UI-24 | Время плетения уходит на сервер при уходе со страницы; прогноз в верхней строке и во вкладке «Время»; выбор интервала перерыва запоминается |
