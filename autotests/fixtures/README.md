# Тестовые данные

| Файл | Что это |
|------|---------|
| `portrait.jpg`, `portrait.png` | Синтетический «портрет», нарисованный скриптом (PNG — с прозрачностью) |
| `face.jpg` | Фото астронавта Эйлин Коллинз (NASA, общественное достояние; взято из набора scikit-image) — для проверки поиска лица и удаления фона |
| `not-an-image.txt` | Текстовый файл для негативных проверок загрузки |
| `prep-golden.json` | Эталон подготовки фото: одинаковые входные пиксели и ожидаемый результат для Python и TypeScript |
| `blank.png` | Однотонная серая картинка 300×300 — на ней нет лица (негативная проверка «Выделить лицо», TC-API-22) |
| `mask.png` | Маска 256×256: белая полоса посередине — «поправленная кистью» маска фона (TC-API-28) |
