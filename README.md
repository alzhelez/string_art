# Нитеграф — портрет из нитей

Загружаете фото — получаете круглую картину из лески на 240 гвоздях (чёрной, чёрной с белой или
цветной) и пошаговую инструкцию, как её натянуть.

**На телефоне, без компьютера:** откройте **https://alzhelez.github.io/string_art/** — всё считается
и хранится прямо в телефоне, работает и без интернета; «Поделиться → На экран „Домой“» ставит его как
приложение. Подробнее — [docs/INSTALL.md](docs/INSTALL.md#телефон-без-компьютера).

**Программа для Windows:** скачайте `Nitegraf-Setup.exe` со страницы
[desktop-latest](https://github.com/alzhelez/string_art/releases/tag/desktop-latest) и установите —
больше ничего не нужно.

**Из исходников** (установка, обновления, запуск — в [docs/INSTALL.md](docs/INSTALL.md)):
`git clone https://github.com/alzhelez/string_art.git`, затем `./scripts/start.sh`
(macOS/Linux) или `scripts\start.bat` (Windows) и откройте http://localhost:3000.

## Что умеет

- **Гвозди.** Круг делится осями X и Y на 4 сектора: **A** — слева сверху, **B** — справа сверху,
  **C** — справа снизу, **D** — слева снизу. В каждом секторе 60 равноудалённых гвоздей, нумерация по
  часовой стрелке. A1 — первый гвоздь над левой точкой оси X, A60 — у верхней точки.
- **Подготовка фото.** Кадр выбирается прямо в круге: перетащить, колесо мыши или два пальца — масштаб.
  Яркость и контраст. Дополнительно: **«Выделить лицо»** (нейросеть YuNet находит лицо, кадр встаёт на
  него, алгоритм прорабатывает его детальнее) и **«Убрать фон»** (нейросеть U²-Net, фон становится
  белым, все линии уходят на человека). Где нейросеть ошиблась — **кисть «Стереть / Вернуть»**
  с отменой.
  **«Автонастройка»** одной кнопкой: находит лицо, по возможности убирает фон и перебирает яркость и
  контраст, пока картина из лески не станет максимально похожей на фото.
  Фото готового портрета можно поправить позже — схема пересчитается.
- **Нити.** Одна чёрная леска; **«Чёрная + белая»** на серой или цветной доске (белая даёт блики);
  **цветные** — 2–4 нити: подбираются под фото автоматически или выбираются вручную. Каждая нить —
  отдельный слой со своей схемой и прогрессом; порядок плетения и число линий каждой нити подбираются
  по сходству всей картины с фото.
- **Размер.** Диаметр круга 30 / 40 / 50 / 60 / 70 см или своё значение 20–150 см.
- **Линии.** 1000–5000, ползунок с мгновенным превью. Рекомендация — количество, при котором картина
  **больше всего похожа на исходное фото**: чёткие черты лица, но ещё не чернота (с учётом диаметра и
  толщины лески); рядом — график сходства.
- **Леска.** Точная длина всех отрезков + запас 15 % и минимальная стандартная катушка
  (100 / 150 / 200 / 300 / 500 / 1000 / 1500 / 2000 / 3000 / 5000 м, дальше — несколько по 1000 м).
- **Пошаговый режим.** Шаг вида **A12 → C37**, автоперелистывание (по умолчанию 2,0 с, кнопки ±0,1 с),
  переход к шагу по номеру, клавиши. Шаг и скорость сохраняются автоматически.
- **Звук шага**: короткий сигнал, голос на русском или тишина.
- **Кино за работой.** Фильм занимает большой экран, а шаг «откуда → куда» и схема — рядом, всё видно
  без прокрутки (на телефоне шаг прилипает сверху). Режим **«Кино»** — фильм на весь экран, шаг и кнопки
  поверх в углу. Источники: файлы с компьютера, YouTube, RuTube, **VK Видео** (ссылка или код
  «Экспортировать»), любой сайт с кодом `<iframe>`. Видео встаёт на паузу вместе с плетением.
- **Музыка — отдельная графа**: код «HTML-код» из **Яндекс Музыки**, ссылка на альбом или плейлист,
  интернет-радио, mp3. Играет под фильм или вместо него, ничего не перекрывает.
- **Светлая и тёмная тема**, удобно и на телефоне.
- **PDF-инструкция**: обложка с картиной и расчётом, схема гвоздей, все шаги с чекбоксами для печати.
- **Шаблон разметки гвоздей 1:1**: круг в натуральную величину на листах A4 или A3 с перекрытием,
  крестиками и подписями A1…D60, метками склейки и линейкой для проверки масштаба печати.
- **Управление без рук**: кликер для презентаций или педаль (PageDown/PageUp, «чёрный экран» — пауза),
  медиа-клавиши и голосовые команды «дальше», «назад», «стоп», «поехали», «повтори».
- **Время**: сколько осталось по вашему реальному темпу, когда закончите при обычном темпе в день,
  статистика по дням и напоминание сделать перерыв.
- **Смена катушки**: укажите длину своей катушки — приложение заранее скажет, после какого шага
  завязать узел и на каком гвозде (там, где больше всего нитей и узла не видно).
- **Сравнение с фото** ползунком и вид **«на стене»** — какой картина покажется с 1–5 метров.
- **Открытка и видео-таймлапс** для подарка: PNG с подписью и ролик 10–30 с, где нити натягиваются одна
  за другой (MP4 или WebM, 1080×1080).
- **Несколько проектов** с прогрессом на карточках.
- **Перенос файлом `.nitegraf`**: «Сохранить файл проекта» в студии и «Открыть файл .nitegraf» на главной —
  схема всех нитей, прогресс, время плетения, фото и маска фона. Так портрет переезжает на другой
  компьютер, в телефон и обратно.
- **Программа для Windows** (.exe с установщиком) — то же приложение в своём окне, без Python и Node.js;
  когда выходит новая версия — кнопка **«Обновить»**: программа сама скачает установщик, проверит его
  контрольную сумму, поставит и перезапустится.
- **Версия для телефона** (GitHub Pages): то же приложение без сервера — расчёт в браузере (Web Worker),
  портреты в памяти браузера, работает офлайн. Нет только поиска лица, удаления фона и PDF — их делает
  программа на компьютере (перенесите туда файл проекта).

Как считается портрет, как мерили точность и что пробовали — [docs/ALGORITHM.md](docs/ALGORITHM.md).

## Структура

```
backend/            Python 3.11+, FastAPI, NumPy, Pillow, OpenCV, ReportLab, SQLite
  app/
    algorithm.py    жадный алгоритм string art (+ карта важности для лица)
    photo.py        подготовка фото: кадр, тона, лицо, фон (+ чистка маски)
    similarity.py   сходство с фото, рекомендация числа линий, автонастройка
    palette.py      нити и доски, сколько каждой нити нужно в каждой точке
    layers.py       цветной портрет: слой на каждую нить, подбор числа линий и порядка
    transfer.py     файл проекта .nitegraf: экспорт, импорт, проверка
    updater.py      обновление программы для Windows в одну кнопку
    geometry.py     гвозди, сектора, хорды
    thread.py       длина лески и подбор катушки
    pdf.py          PDF-инструкция
    main.py         HTTP API (документация: http://localhost:8000/docs)
  app/models/       нейросеть поиска лица YuNet (230 КБ)
  requirements-bg.txt  необязательное удаление фона (onnxruntime)
  tests/            pytest: юнит + API
frontend/           Next.js 16 + React 19 + TypeScript
  app/              страницы: список, студия, редактор фото, плетение
  components/       Board (canvas), PhotoEditor, WeavePlayer, DiameterPicker…
  lib/prep.ts       та же подготовка фото, что на бэкенде, — для живого превью
  lib/local/        версия для телефона: тот же «сервер» в браузере (алгоритм, нити, файл проекта, IndexedDB)
  public/sw.js      service worker: передаёт /api/* «серверу» в браузере и хранит сайт для работы офлайн
  tests/unit/       Vitest + Testing Library (+ совпадение расчёта в браузере с Python)
  tests/e2e/        Playwright: UI (десктоп + мобильный), API-контракт, доступность (axe)
  tests/pages/      Playwright: версия для телефона на собранном сайте
autotests/
  TEST_CASES.md     единый список кейсов TC-API-xx / UI-xx
  fixtures/         общие тестовые картинки и эталон подготовки фото
  java/             TestNG + RestAssured + AssertJ + Allure + PDFBox (Maven)
  go/               стандартный testing + net/http
  ruby/             Minitest + Net::HTTP
  csharp/           xUnit + HttpClient (.NET 8)
desktop/            программа для Windows: окно (pywebview) + сервер, PyInstaller, установщик Inno Setup
scripts/            start.sh / start.bat — запуск одной командой
docs/               установка и обновление, описание алгоритма
.github/workflows/  автотесты при каждом push; сборка .exe → релиз desktop-latest; версия для телефона →
                    GitHub Pages; мутационное тестирование раз в неделю
.gitlab-ci.yml      то же для GitLab CI
```

## Тесты

| Набор | Команда | Где запускать |
|-------|---------|---------------|
| Python: юнит + API | `cd backend && python -m pytest` | ничего поднимать не нужно |
| TypeScript: юнит + компоненты | `cd frontend && npm test` | ничего поднимать не нужно |
| TypeScript: E2E UI + API + доступность (Playwright) | `cd frontend && npx playwright install chromium && npm run test:e2e` | сам поднимает бэкенд на 8001 и фронт на 3001 с временной БД |
| Версия для телефона (Playwright) | `cd frontend && npm run build:pages && npx playwright test -c playwright.pages.config.ts` | сам поднимает статический сервер на 3003 (в CI ещё и iPhone/Safari) |
| Мутационное тестирование | `cd backend && mutmut run && mutmut results`; `cd frontend && npx stryker run` | долго (десятки минут); в CI — раз в неделю |
| Java (TestNG + RestAssured + Allure) | `cd autotests/java && mvn test` → `mvn allure:serve` | нужен запущенный бэкенд на 8000 |
| Go | `cd autotests/go && go test -v ./...` | нужен бэкенд на 8000 |
| Ruby | `ruby autotests/ruby/api_test.rb` | нужен бэкенд на 8000 |
| C# | `cd autotests/csharp && dotnet test` | нужен бэкенд на 8000 |

Адрес бэкенда для API-наборов: `-Dapi.baseUrl=…` (Java) или переменная `STRINGART_API` (Go, Ruby, C#).
Все языковые наборы создают свои проекты и удаляют их за собой.
